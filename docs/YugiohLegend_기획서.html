오디오 레이어

  • 첫 포인터/키 입력으로 BGM 하나를 시작하며, 화면 비가시 상태에서는 일시정지되고 사용자가 시작한 경우에만 다시 재개됩니다.
  • BGM/SFX/음소거 설정은 각각 독립적으로 localStorage에 저장됩니다.
  • 실제 Kenney CC0 Music Loops BGM과 Interface/Impact/Digital OGG 표준 효과음을 사용하며 생성된 PCM 기본음은 없습니다. 위험/결과 덕킹은 0.55, 디코딩된 전체 tail 최소 1.0/0.8초, 최대 8보이스이며 누락/거부 시 안전하게 처리됩니다.
  • Electron은 client/dist를 127.0.0.1의 임시 포트 HTTP로 서비스하며 MIME/경로 순회 방어와 안전한 종료를 갖추고, 별도의 임시 포트 WebSocket을 유지하며 file:// URL은 사용하지 않습니다.

v0.11.0 래스터/ImageGen UI·HUD 검증 메모

  • LP 패널, 버튼, 레인/카드 프레임, 배경, 글로우·슬래시 이펙트 등 HUD·메뉴 요소는 모두 BootScene이 로드하는 AI 생성 PNG 래스터 텍스처이며, client/public/assets/generated 아래에 SVG 자산은 남아 있지 않습니다.
  • LPDisplay의 HUD 패널과 MenuScene 버튼은 yl-surface-frame-9s.png / yl-button-states-atlas.png에 Phaser의 add.nineslice를 적용해, 모서리·테두리 왜곡 없이 크기가 조절됩니다.
  • CardSprite.fitArtworkToSlot은 카드 아트 원본 크기로 cover 스케일을 계산하고 중앙 기준으로 크롭하여, 카드 아트 슬롯에서 원본 비율을 유지한 채 늘어나지 않습니다.

v0.11.1 nineslice 패널 & 온보딩 겹침 수정

  • DeckBuilderScene의 아카이브/덱 패널은 늘어난 ART_KEYS.panel 이미지 대신 add.nineslice(..., 'yl_surface_frame', undefined, W, H, 32, 32, 20, 20)로 렌더링되어, 어떤 패널 크기에서도 테두리가 왜곡되지 않습니다.
  • OnboardingScene은 computeConfirmButtonY로 확인 버튼의 Y 좌표를 계산하여, 세 번째 규칙 섹션 콘텐츠와 72px 확인 버튼 사이에 MIN_CONTENT_TO_BUTTON_CLEARANCE_PX(24px) 이상의 여백을 보장하며, 모달 패널은 1600x900 뷰포트 안에 유지됩니다.
  • 온보딩의 한글 문구(제목, 섹션 제목, 본문, 확인 버튼)는 fontFamily: "'Noto Sans KR', 'Malgun Gothic', sans-serif"를 지정해, Noto Sans KR이 없는 환경에서도 자연스럽게 대체 폰트로 표시됩니다.
