# YugiohLegend — Steam Store Description

## Short Description (30 words max)
카드 소환과 LP 싸움으로 승부를 내는 듀얼 카드 전투 게임.

## Long Description
YugiohLegend는 카드 소환, 함정 설치, 마법 발동을 통해 상대방의 LP(라이프 포인트)를 0으로 만드는 듀얼 카드 전투 게임입니다. 클래식 카드 게임의 규칙을 기반으로, 수백 장의 카드 중 덱을 구성하고 전략적인 플레이를 펼칩니다.

패에서 뽑은 카드를 어떤 타이밍에 어떻게 사용하느냐가 승패를 가릅니다. 몬스터를 필드에 소환해 공격하고, 함정 카드로 역전을 노리며, 강력한 마법 카드로 판세를 뒤집을 수 있습니다.

전설 속 카드들을 모으고, 자신만의 최강 덱을 완성하여 모든 듀얼리스트를 꺾어보세요.

## Key Features
- 턴 기반 듀얼 카드 전투 시스템
- 몬스터/마법/함정 카드 3종 구성
- 덱 빌딩 및 LP 관리 전략 요소

## System Requirements
- **OS:** Windows 10/11
- **Processor:** Intel Core i5 or equivalent
- **Memory:** 4 GB RAM
- **Storage:** 500 MB
