# BGM 수정 이력 — 2026-10-18

대상: 24_YL, 기존 버전 0.9.0. 버전 번호와 원본 음원은 보존했다.

기존 bgm_main_loop.ogg는 메타데이터에 에셋만 제공된 상태로 기록되어 있었으며 실행 코드에 연결되지 않았다. 기존 음원을 첫 입력 이후 지속 재생하도록 연결했다. 브라우저는 디코딩한 버퍼를 반복하며 씬 전환에 소유자를 재생성하지 않는다. 최초 로드 중 숨김/복귀, 반복 숨김, 로드 실패 후 재시도, 음량과 음소거를 공통 회귀 테스트로 검증한다. Godot은 기존 AudioManager 오토로드가 반복 스트림 한 개를 유지한다.

검증: 브라우저 공통 회귀 테스트 7개 통과(각 프로젝트), 전체 기존 테스트는 변경 전 통과. 26_LM은 Godot 4.6 GUT 15개 통과, Windows 내보내기 성공. 21_NL 실제 Electron file:// 로딩에서 OGG 디코딩 1회, 반복 소스 1개 시작을 확인했다. 다른 프로젝트의 실제 청취와 전체 플레이는 미검증이다. 최종 빌드 결과는 별도 인계 JSON과 빌드 로그를 따른다.

Claude CLI가 인증되지 않아 코드/일반 수정 이력은 허용된 Codex 폴백으로 작성했다. GDD MD/HTML 보충은 Claude 전용 정책으로 미완료이며, GDD 완료나 출시 준비 완료를 주장하지 않는다. 신규 유료 미디어, Unity 실행, 배포, 원격 푸시는 수행하지 않았다.
